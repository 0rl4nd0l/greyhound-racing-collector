# Composed race-local metadata exclusion

The 18:53 October 5 odds refresh selected four races, with one eligible and
three excluded. Angle Park R3 had a schema-valid CSV, an aligned final field,
missing target grade, and unavailable native identity due to a recorded
scratched-runner active-price contradiction. The old field-quarantine proof
required successful native identity evidence before replaying the independently
retained primary page, so the two local exclusions could not compose.

The correction authenticates the existing primary-page receipt and bytes,
exact race/time, and canonical CSV alignment before replaying final-field
completeness. An unavailable identity is usable only for this exclusion proof
when the exact existing scratched-price reason and allowlisted missing target
metadata are present. It remains unavailable; no identity is invented and no
excluded row enters the current index. Missing/tampered evidence, unknown
reasons, denied requests, incomplete accounting and invalid eligible inputs
still reject publication. Complete raw and quarantined CSV hashes, schema,
runner counts and runner identities remain mandatory.

The old refresh remains `ACQUISITION_INCOMPLETE`, and its index remains
`REJECTED`. Only a future reviewed package may continue. The existing
`persistent_reviewed_mixed_field_exclusion_v1` recovery schema replays the
entire report through the corrected proof and unchanged native index input
validators. It still binds the exact terminal, phase, cleanup, old HALT/STOP,
allocation and cumulative counters; no recovery-guard change or new allowance
is required.

Validation: the fabricated composed case failed before the correction; 92
focused cases then passed under kernel network denial and filesystem read-only
isolation. They include native publication, old-report rejection, same-allocation
