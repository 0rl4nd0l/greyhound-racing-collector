# Retained market movement qualification protocol — 29 September 2026

Written before any movement-related performance comparison. This is an outcome-blind qualification audit, confined to the exact 331 development race identities / 2,360 runners admitted by #193. Protected reservation manifests and the incident identities are resolved and verified before candidate rows are decoded. No database, provider, runtime, October study, model, label, or history access is required. Audit retained local source files by identity first; a file containing other targets is not permission to decode them.

Fix the decision time at scheduled jump minus two minutes (T−2). Select the latest qualified observation whose independent availability timestamp is no later than that cutoff and whose observation age at cutoff is at most eight minutes. Select the earliest qualified earlier observation within T−30, at least two minutes before the selected late observation. Both must share exact race, runner, WIN market, acquisition source and price-origin bookmaker identities; independently timestamped complete active fields; and explicit scratching/market-status evidence. Reject ambiguity rather than matching by price or using a later price. Scheduled jump is not claimed to be actual off. The retained #193 latest-prejump matrix is availability-selected and cannot alone establish a T−2 replay population.

Audit the canonical corrected-WIN sidecar and the older fixed-window source extract identified in its provenance report, with file hashes and admission gating. Report stage counts, race/date denominators, unavailable fields, duplicates, field changes and every exclusion. Earlier whole-population historical audit summaries are provenance context, not authorization to decode their target records. Do not search live databases for replacement evidence.

Only if the gate passes, coordinate with the root analysis before any performance use. One possible experiment would add two prespecified interpretable runner features to the existing residual: change in log normalized WIN probability and that change divided by elapsed minutes. Normalization removes common margin changes; unchanged complete active fields prevent mechanical scratch-induced renormalization. Retain overround at each point as diagnostics. No raw odds-change feature, later/closing odds, field substitutions, new model families or winner-selected rule. Preprocessing and any two-choice regularization comparison must use earlier chronological training/inner validation only; compare market, unchanged residual and residual-plus-movement on identical races/information, using race log loss/Brier, separate top accuracy, date-cluster intervals and leave-one-date-out sensitivity. Existing inspected data remain exploratory. Do not invent a sample sufficiency threshold after viewing performance; an executable experiment protocol would be frozen after outcome-blind coverage is established.

If qualification fails, run zero fits and zero performance trials and deliver the minimal retention specification and written operational handoff. Missing evidence is a valid terminal finding for this workstream. No returns are calculated.
