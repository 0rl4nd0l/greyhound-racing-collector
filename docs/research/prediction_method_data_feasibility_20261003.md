## What the frozen four actually contain

The methods are `market`, `production`, `residual_box`, and `residual_half`. Production uses 16 finish/margin/recency/experience/context summaries with missingness indicators. The two candidates use those named summaries from canonical retained-card history; `residual_box` adds a literal numeric box and `residual_half` reduces residual strength. All three form methods adjust market probabilities; this suite has no form-only benchmark. [Model membership](../../src/predictor/future_comparison.py:19), [production inputs](../../src/predictor/market_form_residual.py:38), [candidate contracts](../../src/predictor/comparison_candidates.py:11), [candidate scoring](../../src/predictor/comparison_candidates.py:103).

This is **not a clean one-change strength/box experiment**. Production merges earlier database and embedded-card history; canonical candidates use card-only history, deduplication, strict same-day ordering and cap 20. Production's same-distance calculation allows ±50 m; canonical history uses exact distance. Candidates have separately fitted preprocessing/coefficient artifacts. These differences must be held fixed or explicitly isolated in a future comparison. [Production history](../../scripts/run_shadow_non_tgr_rf_evaluation.py:2429), [distance tolerance](../../scripts/run_feature_recovery_execution_v1.py:1588), [canonical history](../../scripts/build_form_only_v1_packet.py:503), [canonical context](../../scripts/build_form_only_v1_packet.py:594), [candidate freezing](../../scripts/freeze_future_comparison.py:68).
